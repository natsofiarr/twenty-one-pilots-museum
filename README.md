# twenty one pilots • museum

Sitio web de un museo ficticio dedicado al universo de **twenty one pilots**: un recorrido por las eras de la banda (Tyler Joseph y Josh Dun), sus personajes, símbolos y el lore de DEMA.

> Proyecto escolar sin fines de lucro, hecho por una fan. Twenty One Pilots y su material pertenecen a sus respectivos dueños.

🔗 **Ver el sitio:** [natsofiarr.github.io/twenty-one-pilots-museum](https://natsofiarr.github.io/twenty-one-pilots-museum/)

## Contenido

### Páginas principales
| Página | Descripción |
|---|---|
| `index.html` | Inicio: sobre el museo, planea tu visita y videos musicales |
| `exposiciones.html` | Lista de las 5 exposiciones permanentes |
| `horario.html` | Horario de visita y días inhábiles |
| `ubicacion.html` | Dirección y mapa |
| `entradas.html` | Precios de entradas |
| `contacto.html` | Formulario de contacto |
| `creditos.html` | Fuentes de información, imágenes y tipografías |

### Salas (una por era)
| Sala | Archivo |
|---|---|
| Blurryface | `blurryface.html` |
| Trench | `trench.html` |
| Scaled and Icy | `sai.html` |
| Clancy | `clancy.html` |
| Breach | `breach.html` |

## Estructura del proyecto

```
├── index.html
├── exposiciones.html
├── horario.html
├── ubicacion.html
├── entradas.html
├── contacto.html
├── creditos.html
├── blurryface.html · trench.html · sai.html · clancy.html · breach.html
├── estilos.css          ← hoja de estilos compartida por todo el sitio
└── *.jpg / *.png        ← imágenes (portadas, fotos y fotogramas de videos)
```

## Tecnologías

- HTML5
- CSS3 (un solo archivo, `estilos.css`, con un tema por era)
- Tipografías de [Google Fonts](https://fonts.google.com): Bebas Neue, Special Elite, Inter, Permanent Marker, Righteous, Anton y Cinzel

No usa JavaScript ni librerías externas.

## Cómo verlo en tu computadora

1. Descarga o clona este repositorio.
2. Abre `index.html` en tu navegador.

No necesitas instalar nada. Para que se carguen las tipografías hace falta conexión a internet.

## Créditos

Los detalles de fuentes de información, imágenes y tipografías están en la página [`creditos.html`](creditos.html).
